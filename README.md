# AI Student Helpdesk Assistant
RAG pipeline that answers student questions from a handbook PDF.
Stack: Python, pypdf, requests, LangChain, [Groq/DeepSeek] API.
Includes zero-shot vs few-shot prompts, keyword-overlap retrieval,
a grounded LangChain chain, and an evaluation of six test questions.
Run: add the API key to Colab Secrets, upload the PDF, Run all.
